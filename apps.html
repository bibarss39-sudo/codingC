اختر البيئة المناسبة لجهازك (حاسوب أو هاتف أو متصفح) وابدأ التطبيق العملي فوراً.

الأكثر استخداماً في الجامعات

Code::Blocks (مع MinGW)

خفيف وسهل التثبيت ومعتمد في أغلب كليات الإعلام الآلي. احرص على تحميل نسخة mingw-setup التي تتضمن مترجم GCC.

احترافي وسريع

Visual Studio Code + GCC

محرر حديث وخفيف مع إضافة C/C++ الرسمية وتكامل ممتاز مع Git والمصحح GDB.

بدون تثبيت

OnlineGDB (مترجم سحابي)

يعمل مباشرة من المتصفح على الحاسوب والهاتف مع مصحح أخطاء مرئي خطوة بخطوة.

للهواتف (Android)

Coding C / Cxxdroid

تطبيقات عملية لتجربة أكواد C وحل تمارين الخوارزميات من الهاتف بدون إنترنت.
